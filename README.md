# Wedding Party

Сайт-приглашение на свадьбу, собранный на Vue 3 + TypeScript + Vite.

## Стек

- Vue 3
- TypeScript
- Vite

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Что реализовано

- mobile-first адаптив;
- секции даты, места, dress code, подарков и RSVP;
- ссылка на карту;
- обратный отсчёт до 25.07.2027 16:00;
- сохранение RSVP в localStorage.

Оригинальные фото и часть точных параметров из Figma ещё нужно заменить на финальные ассеты.
